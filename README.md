# Shortcuts

Shortcuts adds handy keyboard shortcuts for common RimWorld actions.

For example, press `I` to jump to a colonist's inventory. The goal is simple: fewer clicks for actions you repeat all the time.

It is a small quality-of-life mod for players who like keeping their hands on the keyboard.
